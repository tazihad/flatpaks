## Custom Flatpaks

This repository contains a collection of custom Flatpak manifests and build scripts for various applications. These are applications that may not be available on Flathub or require custom configurations (such as Wine wrappers).

## 🚀 Installation
### Option 1: Install Pre-built Bundles (Recommended)

You can install the pre-built .flatpak bundles directly from the Releases page without needing to build them yourself.
